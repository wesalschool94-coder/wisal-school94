# وِصال – بوابة الشراكة الرقمية

بوابة الشراكة المجتمعية للثانوية الرابعة والتسعين – مسارات، بواجهة عربية من اليمين إلى اليسار.

## الأقسام

لوحة الطلاب المتميزين، لوحة أولياء الأمور المتميزين، السلوك الإيجابي، الإعلانات، مدونة الطالب، مدونة ولي الأمر، التكريمات، قصص النجاح، مجلة المناسبات، والعمل التطوعي.

## حالة المشروع

- واجهة الموقع مضافة في `index.html` وشعار المدرسة في `wisal-logo.png`.
- إعداد GitHub Pages يستخدم GitHub Actions عبر `.github/workflows/pages.yml`.
- ملفات الواجهة الحالية ما زالت تحفظ الإدخالات مؤقتًا في الصفحة؛ لم تُربط بعد بقاعدة البيانات.
- ترحيل قاعدة البيانات موجود في `supabase/migrations/20261008190000_initial_wisal_schema.sql` للتجهيز فقط، ولم يُطبّق على أي مشروع Supabase.
- لا يوجد اتصال مفعّل بمشروع وصال حتى الآن. يجب أن يبقى مشروع وصال مستقلًا عن مشروع ارتقاء. لا يوضع مفتاح `service_role` في ملفات الموقع.

بعد إتاحة مشروع Supabase المستقل، يُطبّق الترحيل عليه، ثم تُربط الواجهة بالمشروع ويُضاف حساب الإدارة إلى `public.app_admins`. يسمح المخطط للزوار بقراءة المحتوى المنشور، ويقصر الإضافة والتعديل والحذف ورفع المرفقات على حسابات الإدارة المصرح بها.
